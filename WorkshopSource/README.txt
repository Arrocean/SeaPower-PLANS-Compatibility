中国海军潜艇兼容性Mod

依赖
  095A Runtime（创意工坊 3815454553）
  按 095A Runtime 的说明启用其前置加载器。
  完整的潜艇弹药整合还需要 PLAN Submarines（3594891803）和 PLAN Pack（3775128499）。

使用
  可在 Steam 创意工坊直接订阅本补丁和所需前置模组，Steam 会自动下载。
  在模组列表启用前置模组和本补丁，把本补丁排在它修改的模组之后，重启游戏。
  升级手动安装的旧包时，关闭游戏后整目录替换旧 sppc，清除退役的 sppc.dll。
  停用时在模组列表关闭本补丁并重启游戏。

095A 垂发补弹
  默认、反舰和重型反舰配载保留原有装填量，鹰击-20潜射型和鹰击-18B 各新增 2 枚备弹。
  两种导弹的发射筒分别连接各自的弹仓，由游戏原生机制补装。Console++ 为可选项。

潜艇弹药整合
  09X、095 和 093B 共用 095A 的鹰击-18B、长剑-10潜射型，以及 PLAN Pack 的鱼-9、鱼-10。弹量沿用各艇配置。
  长剑-10潜射型按目标坐标飞行，惯导漂移为零。启用协同中段制导（3838908720）后，可在有有效友方雷达航迹时接收中段更新。
  第一阶段已确认 09X 能使用长剑-10潜射型。第二阶段弹库的游戏内实射与数据链验证待完成。

鱼雷更新
  PLAN Submarines 的 093、093A、039 和 039A 的鱼-6换为鱼-9，094A、039B 和 039C 的鱼-6换为鱼-10电动型。
  095A 的鱼-6A换为鱼-9，095 增配 2 枚可用于拦截的鱼-12A。
  鱼-10电动型最高 60 节，发射距离 0.5–32 海里，断线设置沿用 PLAN Pack。

验证
  在新任务中使用 095A 默认配载，关闭 Console++ 的无限弹药。两种导弹都应有 6 枚预装、2 枚备弹。
  打完预装弹后，确认发射筒补装并继续发射。使用 Console++ 时，可另测开启无限弹药后的连续发射。

工坊内容
  选择本目录作为内容目录，preview.jpg 作为预览图。发布时将 095A Runtime、PLAN Submarines 和 PLAN Pack 列为必需物品。

----- English -----

SeaPower PLANS Compatibility

Enable Type 095A Runtime (Workshop 3815454553) and follow its loader requirements.
The integrated loadouts also require PLAN Submarines (3594891803) and PLAN Pack (3775128499).

Subscribe to this patch and its required items in the Steam Workshop. Steam downloads them automatically.
Enable this patch below the mods it updates and restart Sea Power. When upgrading a
manual install, close the game and replace the old sppc folder to remove sppc.dll.
Disable this patch in the mod list and restart to remove it.

Type 095A VLS reloads
The Default, AntiShip, and AntiShipHeavy loadouts retain their original ready rounds
and carry two more submarine-launched YJ-20s and two more YJ-18Bs. Each group of launch
cells draws from its dedicated magazine through the game's native reload system.
Console++ is optional.

Submarine loadouts
Type 09X, Type 095 and Type 093B share the Type 095A YJ-18B
and submarine-launched CJ-10, plus PLAN Pack's Yu-9 and Yu-10. Quantities come
from PLAN Submarines. The CJ-10 follows target coordinates with zero simulated
inertial drift. Cooperative Midcourse Guidance (3838908720) can supply updates
from valid friendly radar tracks. Type 09X was confirmed to use the submarine-
launched CJ-10 in the initial integration. In-game testing of the expanded
loadouts and datalink updates is pending.

Torpedo changes
Yu-9 replaces Yu-6 on PLAN Submarines' Type 093, Type 093A, Type 039 and
Type 039A. The electric Yu-10 replaces Yu-6 on Type 094A, Type 039B and
Type 039C. Type 095A uses Yu-9 in place of Yu-6A, and Type 095 adds two
Yu-12A torpedoes for interception. The electric Yu-10 reaches 60 knots,
with a 0.5–32 nautical mile launch envelope and PLAN Pack's wire settings.

In a new mission, use the Type 095A's Default loadout with Unlimited Ammo off.
Each missile type should have six ready rounds and two reserve rounds. Fire the
ready rounds and check that the launchers reload and can fire the reserves.
If you use Console++, also test sustained fire with Unlimited Ammo on.

Use this directory as Workshop content and preview.jpg as its preview image.
List Type 095A Runtime, PLAN Submarines, and PLAN Pack as required Workshop items when publishing.
